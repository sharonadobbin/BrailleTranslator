**AI-Powered Automated Braille Translation System - Final Year Project.** 

**Team Members:** Sharon A Dobbin, P Shreya, Sandhya S, Pooja Vijay Bijapur.

This **Braille Translation System** is an accessible, web-based platform designed to address the significant barrier of limited Braille content for visually impaired individuals. The project's core purpose is to simplify the translation process and provide an interactive learning environment for its diverse user base, including **(partially) visually impaired individuals, educators, transcriptionists, and students.**

**Main Features include:** Text-to-Braille, Braille-to-Text, Image to Braille/Text, Document Parser, Learn Braille modules. 

**Translation Core:** Grade 1 and Grade 2. 

**Input Modalities:** Accepts multi-modal input including digital text, file uploads, spoken English, and text extracted from images.
